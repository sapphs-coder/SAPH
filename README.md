# SAPH

SAPH is a creator-first social content studio being designed to help build a distinctive personal brand on Instagram and TikTok.

## Product direction

SAPH will help with:
- Original captions, hooks, calls to action and hashtag suggestions
- A weekly content plan across lifestyle, beauty/fashion, travel, food, fitness/wellness, personal development and daily vlogs
- A reusable creator voice profile
- Later: video-editing assistance, analytics, scheduling and brand-collaboration workflows

## Current status

This repository currently contains the product brief and planning documents. The application itself has not yet been implemented.

See [docs/PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md) for the MVP scope, user journeys, acceptance criteria and roadmap.

## First build recommendation

Start with a mobile-first responsive web app:
1. Dashboard
2. Caption Studio
3. Weekly content planner
4. Creator voice settings

The first prototype should clearly label demo-generated content. Real AI generation, video rendering, direct publishing and analytics integrations are later milestones and must be tested before being described as available.

## Product principles

- Preserve the creator's authentic voice.
- Never invent personal experiences, product use, endorsements or performance metrics.
- The creator reviews and approves every post.
- No automatic publishing in the MVP.
- Be transparent about demo data and unfinished integrations.
